# Marie Hesseberg – studentportfolio

Dette er en statisk nettside som kan publiseres direkte med GitHub Pages.

## Publisering

1. Opprett et nytt repository på GitHub.
2. Last opp `index.html`, `styles.css` og `marie-hesseberg.jpg` til roten av repoet.
3. Åpne **Settings → Pages** i GitHub-repoet.
4. Under **Build and deployment**, velg **Deploy from a branch**.
5. Velg branchen **main**, mappen **/(root)** og trykk **Save**.
6. GitHub viser nettadressen når siden er ferdig publisert.

Du kan redigere tekst i `index.html` og utseendet i `styles.css`.
